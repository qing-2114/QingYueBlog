当前进度已推进到第 4 章 ReAct 实验。`4-experiment/ReAct/agent.py` 实现了
`Thought → Action → Observation` 循环：模型可调用注册工具，工具结果会回灌到下一步
上下文，模型输出 `Finish[最终答案]` 时结束本轮。默认注册的搜索工具使用 SerpApi，
真实搜索仍需本地配置密钥。

该循环已有不依赖模型或搜索 API 的离线测试，覆盖工具结果回灌、直接 `Finish`、格式错误
与最大步数边界。此前的 `1.3-experiment` 旅行 Agent 仍保留：它展示了 V0 偏好记忆、
跨回合接受/拒绝反馈，以及连续三次拒绝时的策略反思；票务数据仍完全是本地模拟，不连接
真实票务平台。
