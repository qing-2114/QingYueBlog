很多人让智能体处理复杂任务，最后习惯在对话框里等一段长长的文字总结。

比如对比十来个同类产品、分析几千行系统日志，或者整理一批测试用例。智能体跑完流程，交出来的是一篇两三千字的 Markdown 文档。格式很整齐，加粗和列表也都规矩。真的看起来，手指得一直划屏幕或者滚鼠标滚轮。

## 线性的文档，装不下多维的分析

长表格排得太宽，在手机上看会被截断。想对比其中两项，得把页面上下翻好几次。要是想换个维度筛选，或者挑出某几类特定结果，只能再给模型发一句提示词，让它重新排版一次。

长篇文字排得再工整，也是一条从头拉到尾的线。阅读的人只能顺着它排好的顺序往下看。

![面对垂直拉长的纯文本文档，反复滚动滚轮查找信息并不轻松](../../assets/agent-html-delivery/01-linear-scroll.png)

这种习惯大多来自早期的对话模型。当时让模型输出长文本最省事，写前端页面不仅容易漏掉标签，样式也经常错乱。

## 为什么现在可以直接交付网页

现在的编程模型和通用 Agent 已经换了模样。写一个自包含的单文件网页，引入基础样式和图表组件，对模型来说是极其熟练的基本功。写一个带交互界面的 HTML 文件，消耗的时间和生成一大段文字差不多。

单文件 HTML 本身极轻便。它不需要搭建前端环境，不需要启动后台服务，双击就能在任何浏览器打开。把这个文件发给同事，对方点开就能用。

把交付结果从一段静态长文字换成单文件网页，看信息的方式会发生三处很直接的变化。

## 单文件网页能多做哪些事

第一处是数据可以自己查，不用被动接收。

在普通的文档里，表格里的内容是固定的。十来个选项排在一起，想找特定条件的项目很费劲。如果交给一个简单的网页，加一个搜索输入框、两组标签筛选，再加上点击表头排序，看报告的人就能按自己的需要挑选。想看更详细的说明，点开折叠面板就能看，不想看就收起来。这让查看结果的人能够按照自己的节奏去找证据。

![带搜索框与标签筛选的交互界面，让数据查找变成自主探索](../../assets/agent-html-delivery/02-interactive-filter.png)

第二处是复杂的流程可以直接跑起来看。

不少任务涉及多步状态变化，例如跨系统的数据同步、审批节点的跳转，或者算法执行的具体阶段。光用文字描述每一步的状态，读者往往需要在脑子里反复推演。如果在交付页面里放一个步骤控制器，点一下“下一步”按钮，页面就高亮当前节点，同时展示输入和输出，整个过程的逻辑一目了然。

第三处是交付文件可以随着任务持续改动。

一段文字汇报发出来就停留在聊天记录里了。一个 HTML 文件可以当作持续演进的工作台。智能体跑完第一轮数据，先把表格放进去。后续有了补充实验或者新的用户反馈，就在同一个页面上追加图表、更新说明。成果在同一个文件里逐步完善，而不是零散地散落在多次对话的断片里。

## 什么时候用 Markdown，什么时候用 HTML

这些好处不代表要把所有产出都做成网页。界面有界面的长处，纯文本也有纯文本的边界。

| 任务场景 | 推荐格式 | 选用理由 |
| --- | --- | --- |
| 简短答复或单一结论 | Markdown | 两三句话就能说清，纯文本最轻便 |
| 需要 Git 版本控制的文档 | Markdown | 纯文本易比对差异，长期存储与检索成本低 |
| 个人知识库与关联笔记 | Markdown | 便于双向链接，内容干净且不易损坏 |
| 多维度数据筛选与下钻 | HTML | 支持搜索、排序与标签过滤，方便自助查验 |
| 复杂状态机与业务流演示 | HTML | 具备步骤控制器，流程可操作且直观可观察 |
| 持续迭代的实验与测试汇报 | HTML | 页面可随进展追加图表，集中汇集最新成果 |

适合用 HTML 交付的，通常是那些带有比较、带有筛选、带有流程演示，或者包含多组数据对比的复杂成果。

## 避开虚假界面的花架子

有一点需要格外留心。不要让智能体堆砌虚假的界面。

有些页面看起来有模有样，按钮点下去毫无反应，图表里的数字是前端写死的假数据，甚至找不到原始数据的出处。这类花哨的页面只会制造混乱。

![交互界面上的图表与数字，必须能对应回底层的源文件记录](../../assets/agent-html-delivery/03-traceable-data.png)

一个实用的交互交付件，必须清楚标明数据是哪一天采集的、依据来自哪些源文件、页面上的图表能不能对应回底层记录。数据真实、来源可核，界面才有意义。

下次再让智能体做竞品梳理、日志归类或者多方案评估时，不妨在指令末尾加上一句要求，让它交付一个带有筛选功能的单文件 HTML。把页面拖进浏览器的瞬间，你会发现很多原本需要反复翻找的信息，用几次回车和点击就能看清楚。
