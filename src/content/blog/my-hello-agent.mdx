基于 [Datawhale「Hello Agents」](https://hello-agents.datawhale.cc/) 的学习项目，现已推进至第十四章相关实践，覆盖的章节并不连续。最新提交为 `7a3fe96`，集中加入评估、旅行助手与深度研究实验。

## 从工具接入到应用协作

第十章按 MCP、A2A、ANP 分类整理实验。MCP 天气助手通过真实模型调用工具，主天气源失败后可使用 Open-Meteo；A2A 包含模型驱动的客服与规则驱动的协商；ANP 包含服务发现、网络和调度示例。

第十二章开始给模型工具调用做评估：BFCL `simple_python` 前五条真实 API 预测，HelloAgents 内置 AST 评分及官方 CLI 的 partial-eval 复核均为 5/5。这只是小样本流程验证，完整 BFCL 和 GAIA 评测仍待推进。

## 自己的旅行助手

第十三章除了保留官方参考样例，还实现了独立的 `trip-assistant`：景点、天气、酒店与规划四个 Agent 顺序协作，接入高德 MCP 和 Unsplash。Vue 页面支持行程编辑、预算更新、地图导航、PNG/PDF 导出。

11 月 3 日的验证记录覆盖真实 API、北京一日游浏览器流程、两日 HTTP 行程、地图、编辑、导出与窄屏交互。天气进一步加入 HKO 和 Open-Meteo，按预报覆盖日期补缺并显示来源。天气的全球覆盖不代表景点与酒店搜索已具备相同覆盖范围。

## 自己的深度研究工作台

第十四章的 `research-assistant` 由规划、总结与报告三个角色协作。规划后逐任务搜索，摘要保留来源编号和 URL，再汇总报告；NoteTool 保存计划、任务资料及报告，搜索结果支持去重、长度预算与缓存。

FastAPI 使用 SSE 向 Vue 工作台发送阶段进度、任务总结和报告，支持 Markdown 下载和停止研究。真实 HTTP → Tavily → 模型完整链路与桌面、手机浏览器检查已有通过记录。笔记用于事后读取进度，自动断点续跑仍待实现。
